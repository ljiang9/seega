# Seega 塞加棋

古埃及流传下来的 5×5 棋盘游戏：布子、走子、夹吃。纯 Python 标准库，无第三方依赖。

## 玩法

- **棋盘**：5×5，双方各 12 子，中央格（☆）初始为空，是**安全格**（上面的子永不被吃，也不能在上面布子）。
- **布子阶段**：双方轮流每次布 2 子，布满 24 子后进入走子阶段。
- **走子阶段**：每次把一枚自己的子正交走一格到空格。
- **吃子（custodian capture）**：走子落定后，若敌子被夹在「刚走到的子」和另一枚己子之间（正交直线），则被吃掉；一次走子可同时从多个方向吃子。自己主动走进两枚敌子之间是**安全**的，不会被吃。
- **胜负**：吃光对方所有子者胜；轮到走子时无合法走法者判负。

## 运行

```bash
python3 -m seega                 # 人机对战（你是 ● 先手）
python3 -m seega --auto          # AI 对 AI 自动演示（10 局）
python3 -m seega --auto --games 20 --seed 7 --verbose
```

布子输入 `行 列`（如 `2 3`），每轮布 2 子；走子输入 `起行 起列 落行 落列`（如 `2 3 2 4`）；`q` 退出。

## 设计取舍与已知局限（诚实版）

- **吃子规则采用"双子夹击"**：必须由两枚己子夹住才吃，靠棋盘边沿不算吃子。历史上的 Seega 各地规则本就不同，这里取了最常见的一种，README 如实说明。
- **中央安全格**：部分古规则中没有安全格，这里保留了"王座安全"的常见变体。
- **AI 只是贪心**：吃子优先、其次贴近敌子，不做深层搜索；熟悉规则的人类通常能赢。
- **布子 2 子/轮**是现代简化下法。
- 文本回合制，无图形界面、无存档、无悔棋；Python 3.10+。
